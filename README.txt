MYGARAGE — PRIMERA VERSIÓN
==========================

Qué incluye
- Garaje de motos actuales y anteriores.
- Lista de deseos.
- Fichas técnicas editables.
- Comparador de hasta tres motos.
- Guardado local en el navegador.
- Exportación de copia de seguridad JSON.
- Diseño responsive para iPhone.
- Base PWA: manifest, iconos y service worker.

IMPORTANTE SOBRE INSTALAR EN IPHONE
Esta carpeta es el código de la app. Para instalarla desde Safari como icono en la pantalla de inicio, debe publicarse primero en una dirección HTTPS. Después:
1. Abre la URL en Safari en el iPhone.
2. Pulsa Compartir.
3. Elige "Añadir a pantalla de inicio".
4. Activa "Abrir como app" si aparece esa opción y pulsa Añadir.

Los datos se guardan en el almacenamiento local del navegador/app y no se sincronizan con otros dispositivos. Borrar los datos del sitio o cambiar de navegador puede hacer que se pierdan. Usa el botón de exportación para guardar copias de seguridad. Para restaurar una copia, mantén pulsado el botón de exportación y selecciona el archivo JSON.

La app no descarga fichas de fabricantes ni verifica automáticamente las especificaciones. Introduce datos contrastados manualmente. Las imágenes de motos reales y la búsqueda de modelos se pueden añadir en una siguiente versión.

Para probar en ordenador:
- Descomprime el ZIP.
- Sirve la carpeta con un servidor web local (no basta con abrir index.html para probar el modo PWA).
